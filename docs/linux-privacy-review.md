# Linux 隐私审查 / Linux privacy review

审查日期：2026-10-13。审查目标：叠绘 Linux x86_64 `0.4.0-alpha.1` 候选版源码与 AppImage、Deb、tar.gz 安装包。

## 审查结果

- 编辑、打开和保存项目不需要账号或网络服务。项目、自动恢复副本、保存日志和界面偏好保存在本机 Linux 用户数据目录；没有遥测、广告、自动更新或托管编辑服务。
- 主进程只在用户主动使用可选 AI 助手或测试连接时请求用户配置的 HTTPS 接口。默认接口为 DeepSeek；用户也可以改用其他兼容服务或本机回环服务。
- AI 请求包含用户输入的提示词、所选模型，以及图层 ID、名称、可见性、不透明度、混合模式、分组关系、调整类型和是否含蒙版等描述。API 密钥随请求以 Bearer 授权发送。图像像素和 `.comp` 项目文件本身不会发送；测试连接发送 `ping` 和空图层列表。服务商对请求数据的保存方式由用户所选接口的政策决定。
- Linux 仅在 Secret Service 或 KWallet 可用且加密后端合格时保存 API 密钥。Chromium `basic_text` 回退或无密钥环时会拒绝保存。端点只允许 HTTPS，或本机回环 HTTP。密钥可在 AI 设置中清除。
- Renderer 的内容安全策略限制其自身只能连接应用内容；外部 AI 请求由主进程发起。发行启动器保留 Electron 沙箱，不注入 `--no-sandbox`。

## 检查范围与证据

检查了本次 Linux 源码、工作流、文档和提交流程相关文件；对三个 Linux 包中的应用源码进行用户目录路径和常见密钥格式扫描，并核验包内依赖声明、许可证、文件清单和应用身份。扫描没有发现匹配的私人目录路径或凭证。构建包、测试报告、合成项目与本机日志位于忽略目录，不属于源码提交内容；项目使用合成测试数据。

隐私检查和安装包审计通过。审查脚本覆盖 Linux `/home`、`/root`、macOS `/Users`、Windows 用户目录以及常见密钥格式；这类静态模式扫描不能证明不存在所有形式的敏感信息，也不等于第三方安全渗透测试。

## 尚未验证

没有对真实 GNOME/KDE 桌面进行数据包捕获或密钥环恢复测试；AI 第三方服务未连接，KWallet 尚未验证。真实桌面验收仍待完成。使用 AI 时，提示词和图层名称可能包含个人或项目敏感信息，请先确认所配置服务适合接收这些内容。
