# Windows 第 3 批：编辑候选版

版本：`0.2.0-alpha.1`。Windows 与 macOS 同仓库、独立应用；不修改原生 macOS 代码、项目、安装包、设置或更新入口。第 2 批未交付的编辑、历史和保存基础一起完成。

## 开放范围

| 项目 | 本版行为与边界 |
| --- | --- |
| 图层与画布 | 新建画布、宽高互换；像素层、组、复制叶子层、删除、排序、组归属；位置、大小、旋转、翻转、可见性、不透明度 |
| 绘画 | 画笔/橡皮擦，一笔一次撤销；像素或蒙版目标。文字/形状绘画后明确删除可编辑元数据，撤销可以恢复 |
| 混合 | 24 种模式使用候选 sRGB 合成配置；不宣称与 macOS 像素完全一致 |
| 蒙版与剪贴 | 灰度蒙版、启停、反转、链接与独立位置、组蒙版；只编辑同级、连续、直接依赖像素底层的剪贴栈。链式或非连续剪贴保留只读 |
| 调整 | 色相/饱和度、色阶、曲线、曝光、渐变映射、颗粒、反相、黑白、色彩平衡、高斯模糊、动感模糊、杂色；高级或未知参数保留只读 |
| 效果 | 描边、投影、颜色叠加、内阴影、外发光、内发光；空间算法仍需黄金图定标 |
| PSD 导入 | 预算内的 8 位 RGB PSD：基础像素、穿透组、不透明度、混合、蒙版；不支持组合必须由用户明确选择导入合成像素或取消 |
| PSD 导出 | 基础像素/组/位置/不透明度/混合/蒙版分层导出；文字/形状为像素。调整或效果只允许明确选择扁平导出；不支持 PSB |
| 文件 | PNG/JPEG 图像导入、PNG 导出；`.comp` 1–11 读取、原记录与未改资源保留；不增加格式字段 |
| 界面 | 参考 macOS 的暗色画布、左侧工具、右侧图层与参数；Vue 重写适合 Windows 的交互；中文/英文切换持久化 |

未知或未支持的渲染属性阻止视觉编辑，使用保存的预览或只展示元数据。名称编辑仍允许；不会将部分渲染当成正确结果。

## 保存与失败处理

- 主进程是文档与历史的唯一写入方。每次操作绑定文档 ID 和修订号；旧笔画、旧资源 URL 和旧回调不得修改当前文档。候选副本完整验证后才进入历史，批量失败不留下半完成编辑。
- 历史最多 80 步，按共享不可变资源计算 256 MiB 预算。编辑后延迟写用户数据目录中的恢复副本，不调用标记已保存的路径。
- 另存和覆盖先写同目录暂存包并回读校验；覆盖验证当前源指纹，写提交日志，保留完整旧目录，再提交新目录。该流程不称为整体原子替换。
- 云端通过进程强制退出模拟三个中断点：写日志后、旧目录移动后、新目录提交后。启动恢复保留或恢复完整项目；不确定状态交给人工处理。
- 被其他程序占用时有限退避重试，并返回可读错误；未验证真实 Defender/OneDrive 占用组合。建议在本机非同步目录工作。

## 审查与验收

用户要求不运行本地测试。本次类型检查、单元/文件行为、独立 PSD 读取、安装器构建和已打包 EXE 的 GUI 检查全部交给 Windows GitHub Actions。公开发布以前要求对应源码 SHA 的完整云端工作流通过，并检查实际包、许可证、隐私模式、公开附件哈希和 macOS Latest 落点。

合成回归包括：格式/路径/资源/内存限制，未知键和资源保留，失败批量与旧修订拒绝，撤销重做，源文件未改，另存/覆盖/外部修改拒绝，中断恢复和恢复副本，调整/效果像素检查，PSD 自回读和独立 `psd-tools` 读取。GUI 检查涵盖基础显示、中英文重启、隔离接口、复杂项目回退、拖入/搜索/折叠/复制匿名报告，以及编辑/保存/24 混合/调整/效果/蒙版/导出/笔画/新画布。

**尚待人工验收**：Win10/11 真机安装卸载、真实显卡与上下文丢失、DPI/中文输入法、长时间大文档性能、Mac→Win→Mac 黄金图、真实 Photoshop 或 Photopea 打开。不得用云端软件 GPU 通过替代这些项目。因此发布为预览版，调整/效果和混合仍标注候选渲染。

## 安装

见 [中英文安装说明](windows-install.md)。下载当前 Windows 预发布附件中的 x64 安装 EXE，或完整解压 ZIP 后启动 `Compositor.exe`。恢复副本与备份包含项目内容，清理和位置说明一并写在安装文档中。
