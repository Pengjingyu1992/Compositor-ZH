# Windows / Linux 与 macOS 功能对照及移植记录

参考：`origin/main` 的 macOS 40.41，提交 `f8b1457`。目标是移植已经实现的用户能力；macOS 中仍属规划的智能对象、动作录制、多画板、完整 16/32 位编辑和 CMYK 文档不计作现有功能。macOS 源码、工程和发行渠道不在本次修改范围。

Windows/Linux 共用 `windows/`，实现一份并分别构建验证。表中“待实现”不能作为已交付功能宣传；入口、保存/恢复、撤销、锁定、取消、跨端项目互通和实际包验证共同构成交付条件。

| 能力 | 当前共享版本与差异 | 本次状态 |
|---|---|---|
| 基础绘画、选区、图层、动画 | 已有共享实现；算法与设备表现需分别验证 | 保持并回归 |
| v17 原始 PNG、色彩管理、方向与编辑代理 | 已接入原始资源/代理分离、ICC 与方向处理、原图保存/恢复及像素替换 | 单元及 Linux 实际包测试通过，待两端完整 CI |

| CMYK ICC 软打样与四通道 TIFF | 没有对应工作区 | 待实现 |
| RAW 导入/开发 | 当前无 RAW 解码与开发工作区 | 待实现 |

## 共同验证约束

- 合成样本覆盖原始资源字节保持、像素编辑后资源替换、保存重开、恢复与撤销。
- 新格式记录严格验证，未知或损坏数据明确拒绝，不通过提高版本上限或删除记录来伪装兼容。
- Windows 与 Linux 的实际安装包各自运行测试；真实输入法、压感设备、硬件 GPU 和高 DPI 另列验收。
- 更新仓库时保留 macOS 文件和发布，Windows/Linux 各用独立产物与发行渠道。
