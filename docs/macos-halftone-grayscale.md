# macOS 40.22：圆形半调与灰度副本

## 使用

1. **图像 → 转换为灰度副本…**：确认后，把当前可见画面合成为一个 8 位灰度图层，在新的标签中打开。尺寸、透明度、DPI 保留；原项目的图层及撤销记录保留。副本可以保存为 `.comp` 或导出普通图像。
2. **滤镜 → 彩色半调**，或可编辑滤镜中的彩色半调：选择圆形网点，设置最大半径、通道网角和强度。
3. **自动通道**会对中性灰图使用单组网点，对彩色图使用 RGB 三组网点。也可明确选 RGB 或灰度；灰度使用“灰度网角”。
4. 旧项目默认继续使用**传统 CMYK 印刷**。要使用新算法，在网点通道中选择自动/RGB/灰度。

灰度副本属于图像转换功能。合成后的灰度资产使用单灰度分量与 alpha；编辑器仍使用 RGB 工具，之后可以重新绘入颜色。普通图像导出经现有 sRGB 合成路径，像素为中性灰但文件可能仍为 RGB 编码。它不是 Photoshop 的完整灰度文档模式；后者及其他模式、位深另见[颜色引擎方案](macos-color-engine-plan.md)。

## 半调改变

- 旧实现从单一中心像素取样，并把网点限定在各自网格；相邻网点半径变化时，跨格圆弧会被截断。
- 新实现对每个旋转网格取 16 个样本，按 alpha 加权求色调；透明像素不贡献颜色。逐个绘制完整圆点，在交叠处合并 4×4 子像素覆盖，而非裁切到单元格。
- 彩色通道由 RGB 分别生成网点；灰度使用单组网点。默认通道角为 108°、162°、90°，灰度角为 45°，默认最大半径 8 像素。可选方形/线形和强度混合。
- 较深区域的圆点仍会自然连接；小半径与低缩放下受像素分辨率限制。不能把相连的深色区全部变成互不接触的圆点而同时保持其覆盖率。
- 新通道网点需要一份每像素 2 字节的临时覆盖缓冲；分配失败时整次滤镜拒绝提交。

[Adobe 的色彩半调说明](https://helpx.adobe.com/photoshop/desktop/effects-filters/artistic-stylize-filters/apply-distortion-and-stylize-filters.html)描述了最大半径与通道网角。本实现独立编写，没有使用 Photoshop 内部实现；不能据此宣称与 Photoshop 像素完全一致。

## 保存兼容

旧算法配方维持 v14；新通道半调配方使用 v15。普通图像或栅格化副本仍写 v13。当前 Windows 桥接不能打开 v14/v15；交换时保留原项目，再导出图像/PSD或在副本上栅格化。新读取器支持旧配方，无 `screen` 字段时保留原效果。

源文件：`PosterPixels.c/.h`、`PosterColor.swift`、`PosterFilterControls.swift`、`GrayscaleConverter.swift`。灰度副本只在完整转换成功、源文档与修订仍一致时创建标签，失败不替换原项目。
