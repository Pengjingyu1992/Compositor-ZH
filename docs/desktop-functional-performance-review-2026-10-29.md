## 已修复问题与测量

### 1. 大选区令界面每次拖动停顿数秒

在上一发布到开发分支的应用包上，1920×1080 全选后拖动选框，单次按下处理约 **5659.7 ms**，移动事件 P95 约 **4480.2 ms**，性能检查真实失败（按下预算 350 ms、移动 P95 预算 120 ms）。

原因有两处：手势快照先把整块选区字节展开为 JSON；每次移动又重设画布尺寸，并通过 Vue 响应式属性逐像素重新生成完整选区遮罩。修复保留选区的独立字节快照，跳过 JSON 展开；遮罩按不可变选区字节及尺寸缓存，改变选区时重建，关闭项目／卸载时释放。

在同机第一修正包中，按下 **16.8 ms**、移动 P95 **11.0 ms**；随后包含生命周期修正的包中为 **31.0 ms／12.7 ms**。最终包的本机定向为 18.8 ms／11.1 ms，完整回归中的样本为 13.7 ms／43.0 ms；两者都保留，未只选择较快样本。这些是浏览器事件同步处理时间，不能换算为硬件 GPU 帧率或所有功能的统一性能增幅。

取消手势后核对边缘与内部 RGBA，取消选区后遮罩清空；扩展、收缩、羽化、反选、撤销和尺寸变化另有功能断言，避免缓存保留旧图像。

### 2. 动画播放期间蒙版按钮仍能切换绘制目标

旧包的普通图层选择已锁定，但蒙版缩略图只检查绘制状态。实测在播放中激活它，绘制目标从 `content` 变成 `mask`，即使图层选择函数已经拒绝切换。复现检查明确收到错误的 `mask` 值，记录单独保留。

现在蒙版按钮与图层按钮共用播放／渲染／忙碌／绘制锁定条件，目标切换也放入选择函数的状态检查内；暂停后仍可正常切到蒙版，不影响项目文件格式或像素算法。
