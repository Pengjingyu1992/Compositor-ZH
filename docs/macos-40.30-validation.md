# macOS 40.30 第一批改进记录

日期：2026-10-19。版本：1.4.8（40.30）。范围为质感与性能续评估方案的 A1、A2、A3。

## 实现

- 变换参数栏保留 X／Y／W／H 与比例锁；按参数栏实际可用宽度显示次级控件。“工具选项”提供位置、尺寸、缩放、旋转、采样、双向翻转及对齐入口。
- 取消／应用只在需要确认的编辑中占位；画布既有 Esc／Return 路由保留。紧凑栏补齐文字、裁剪、路径和渐变编辑的结束操作。
- 完整工具选项改为可换行、可纵向滚动的表单，按内容高度收缩；数值控件保持单位及标签成组，变换的核心输入在缩放窗口时保留视图身份。
- AppKit 与 SwiftUI 使用同一外观选择；跟随系统清除应用覆盖，原生打开／保存对话框和独立面板继承选择；移除高级液化强制深色。
- 取消普通滤镜预览向独立计算任务传递取消。同一文档通过串行预览执行器处理，丢弃已取消的排队请求；新结果提交前检查文档身份及修订号。
- C 噪点、镜头变形、马赛克和色彩半调在行／块边界检查原子取消标记。Swift 像素处理和 Camera Raw 在阶段边界检查取消。已开始且没有中断接口的底层调用／GPU 工作安全结束后停止后续阶段，不承诺瞬时终止。
- 应用滤镜前先清空待处理预览并等待旧计算退出；所有退出路径释放编辑持有者，提交仍是一条撤销记录。

本批未改变 `.comp` 格式，仍为 v16、兼容 1–16；未新增依赖。

新增文件：`Compositor/Rendering/FilterCancellation.h`、`FilterCancellation.c`、`CompositorTests/PolishFirstBatchTests.swift`、`scripts/check-polish-clt.zsh`。同步源码目录自动将 C 文件纳入 Xcode；CLT 构建脚本同样编译该文件。
