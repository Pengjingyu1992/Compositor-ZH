# 已选方向：接近 macOS 的桌面编辑器

用户在对话中明确要求“尽量贴进MacOS版UI风格”。A/B/C/D 仅保留为前期探索，实际实现参照原生 macOS 40.41（`f8b1457`）的 `EditorTheme.swift`、`ToolHeaderStyle.swift`、`ProjectTabs.swift`、`LayersPanel.swift` 与 `ContentView.swift`。以 [DESIGN.md](../../DESIGN.md) 为设计锚；本次不修改原生 macOS。

## 实际实现

1. 中性灰背景、系统字体与蓝色交互色；浅色、深色和跟随系统三种外观使用语义颜色。外观保存在本机，迁移旧设置时保留网格、标尺和色板。
2. 项目名称只出现于顶部的 28 px 胶囊标签。保留修改标记、独立关闭、键盘切换、完整名称提示及多项目保护；缩放、检查器和导出入口成组排列。
3. 40 px 工具参数栏、52 px 工具轨、32 px 工具按钮；编辑工具独立滚动，手形、缩放与前景／背景色固定在底部。参数栏支持横向滚动，避免出现一像素高度溢出的纵向滚动条。
4. 280 px 检查器、完整背景的选中图层和分段式属性标签；检查器可用鼠标或键盘隐藏。小窗口保留图层区最小高度，暂隐图层类型副标题，名称和选中态保持清楚，属性区仍可独立滚动。
5. 新配置的 AI 面板默认折叠，尊重已有配置中的展开偏好；设置入口保持可达。对话框、曲线、标尺和反馈颜色适应外观，图像像素、蒙版与透明背景棋盘保持原有处理。

原生参考的控件字号为 11 px；跨平台界面采用 13 px 系统中文主界面、14 px 说明文字，保留工具数值的紧凑尺寸。不引入远程字体、第三方图像、外部设计模型或新增运行时依赖。Windows/Linux 保留各自系统标题栏、应用身份、设置目录和发行通道。

## 两轮实际运行复核

| 视角 | 首轮发现 | 修正与复核 |
|---|---|---|
| 视觉与可读性 | 高亮蓝在深色模式下不适合配白字，部分曲线和标尺仍固定深色 | 将文字上的蓝色与按钮填充蓝分开，曲线、标尺与错误反馈使用语义色；检查实际浅／深色截图 |
| 工程与状态 | Vite 把 `light-dark()` 编译为媒体查询兼容写法，显式深色仍显示浅色 | 为内置 Chromium 指定 CSS 目标；真实包断言面板颜色，并检查跟随系统、重启恢复和不变的画布像素 |
| 编辑任务 | 小窗口图层区被固定控件挤压，第二个选中图层部分或全部不可见；工具参数栏出现纵向滚动条 | 小窗口保留两行缩略图／名称空间并收起类型副标题；修正参数栏内边距与滚动方向，保留失败记录并用完整可见断言复查 |
| 内容与操作 | 旧界面重复显示项目名称，AI 默认展开占用画布，长名称缺少完整提示 | 合并单一项目标签，AI 默认折叠，标签加入完整名称提示；复查键盘焦点、独立滚动及中英文标签 |
