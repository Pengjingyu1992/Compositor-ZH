# 叠绘 Windows / Linux UI 方向预览

日期：2026-10-29（Asia/Shanghai）。用户已在对话中明确选择“尽量贴进MacOS版UI风格”，正式实现按原生 macOS 的样式与布局推进；下方 A/B/C/D 保留为方向探索记录，不代表最终界面。

最终设计锚见 [DESIGN.md](../../DESIGN.md)，实现与验证见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

依据用户指定的 [qiaomu-design](https://github.com/joeseesun/qiaomu-design) 技能，读取版本 `ccd9cecb5b1f1e994eebf7bd814f2f0c35fe3bea`。四方向使用独立 brief 和 CSS 作用域生成；推荐 A 不代表已经选择。

功能契约：三秒内看清当前项目、画布、工具和选中图层；保留创建/导入/保存、多项目、图层/蒙版、属性/调整/效果和 AI 入口；画布优先，窄窗口下关键操作仍可达。macOS 原生应用、项目与发行不在范围。

| 方向 | 明暗与气质 | 字体角色 | 布局 | 密度/材质 |
|---|---|---|---|---|
| A 石墨专业（推荐） | 当代深石墨/薄荷绿 | 系统中文 + 等宽数值 | 左工具、右图层/属性、单项目栏 | 高密度，轻分层 |
| B 瓷白工作室 | 当代亮瓷白/鼠尾草绿 | 系统中文 + 圆润西文 | 横工具、左图层、底属性 | 中等密度，柔和圆角 |
| C 精密仪器 | 工业钢灰/青灰/琥珀 | 系统中文 + 等宽命令/数值 | 左工具与图层、顶参数带 | 高密度，方正刻度 |
| D 纸感画室 | 复古暖纸/墨色/朱红 | 系统中文 + 西文衬线标题 | 项目标题、宽画布、底图层接触表 | 低密度，平面纸质 |

入口 `index.html` 自包含，无远程字体、图片、依赖或用户项目；图像均为本次绘制的合成 SVG。放大预览支持可控滚动，移动端选择区保持单列。

点方向只打开确认弹窗；确认后才 POST 到本地预览服务并写入 `selection.json`。实际选择以用户对话为准，已记录到本地忽略的 `selection.json`。测试回传使用隔离目录，不作为用户选择。

验证：Chromium 实际运行。1440 px 桌面两列、390 px 手机单列，无页面横向溢出；四个完整样机均为 960 × 600，无内容溢出。通过放大/关闭回焦、滑块即时数值、数字键选择、Escape、失败回传保留建议并重试；实际 POST 与 JSON 持久化在隔离测试服务验证，此处测试不冒充正式用户选择。无外部请求或浏览器异常。

两轮截图复核：首轮发现 A 的属性底部溢出；第二轮收紧图层区、明确分组，旋转字段与状态栏恢复完整。中文强调统一到 600，正文行高统一到 1.5；细节可通过放大样机检查，避免缩略图影响判断。当前截图见 `desktop-preview.png`、`mobile-preview.png`、`direction-a.png` 等，测量见 `preview-review.json`。
