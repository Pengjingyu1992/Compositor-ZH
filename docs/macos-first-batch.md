# macOS 第一批：可靠性、图层锁定与历史记录

版本：1.4.5（40.12）。本批对应合并计划 T01–T05，同时确定后续命令契约。

## 使用

- 图层面板新增五个锁定按钮；也可从「图层 → 锁定」选择内容、位置、外观、透明度或全部锁定。组的锁定会传递给后代，图层名称前显示锁标记。解除继承锁需要选择上级组。
- 锁定仅在当前文档会话内生效，不写入 `.comp`，不产生文件未保存标记。锁定期间仍可选择、读取/复制和撤销/重做；历史恢复不被锁定阻挡。
- 右侧面板顶部可切换「图层 / 历史记录」，「显示 → 历史记录」也可打开。点击步骤跳转；灰色步骤可以重做。跳回后继续编辑会移除旧的重做分支。磁盘标记表示最近保存的修订。
- 历史面板只读取现有历史元数据，共用 100 步和 256 MiB 的默认预算。预算裁剪后的首项显示「更早的状态」。若单次编辑的旧像素超出预算，状态栏和历史面板会明确提示本次无法撤销。临时对比快照留待后续，不把恢复副本显示为历史快照。
- PSD 导入提示、动态文件名和字体名使用固定本地化模板。可与本机文字布局精确对齐的 PSD 文字缓存会被保留，文字仍可编辑；首次改文字会使用本机排版。无法对齐、旋转或不兼容的布局明确提示重新排版，未宣称通用 Photoshop 保真。

## 锁定规则

| 锁定 | 阻止 | 允许 |
|---|---|---|
| 内容 | 像素、文字、形状/调整元数据、蒙版内容、剪贴来源变化 | 位置及独立外观调整 |
| 位置 | 图层与独立蒙版变换、蒙版链接状态、所选像素移动/变换 | 原坐标内的内容编辑 |
| 外观 | 不透明度、混合、可见性、图层效果、蒙版启停 | 原始像素编辑 |
| 透明度 | 改变像素 alpha、擦除/清除、改变透明度的滤镜结果 | 保持逐像素 alpha 的画笔、填充与调色 |
| 全部 | 以上及图层改名 | 选择、读取/复制、历史恢复、解锁 |

任意锁定的层均不可删除、合并或重新分组；也不能通过改变祖先组绕开锁定。锁定组的内容或全部属性后不可往其中插入图层。未覆盖的调用在外层事务提交时验证，违反规则整批恢复且不新增历史。

透明度锁保持半透明边缘的 alpha，不将它二值化。画笔按触及的块处理；提交检查在像素变化时复核 alpha。位置锁下若绘画扩展了图层的像素边界，会拒绝改变变换的提交。

蒙版像素、位置/链接和启停分别受内容、位置和外观锁控制，避免内容锁误拦截位置或启停。退出时会取消尚未确认的图层效果面板；关闭调色、滤镜或效果预览后，会继续处理排队的文件请求。

## PSD 差异归属

使用自行生成的 1200×800 七层合成样例，包含中文文字、贝塞尔形状、智能对象的滤镜缓存及蒙版、默认曲线、普通像素层和隐藏渐变。

修复前与 Photon 导出的合成图相比：10,071 个像素有差异，5,922 个超过 1/255，最大差异 212/255。逐层/缓存替换实验将超过 1/255 的差异定位到文字重新排版；该样例中的路径、智能对象缓存/蒙版和默认曲线未发现超过 1/255 的差异。这不证明所有非默认曲线或其他 PSD 都一致。

修复后仍有 6,128 个像素出现 1/255 的差异，没有超过 1/255 的像素；最大差异由 212/255 降至 1/255。智能对象和任意路径仍按已有能力栅格化，文字外观保留不等于增加路径或智能对象持久模型。

## 验证方式

```sh
./scripts/check-localization.zsh
./scripts/check-first-batch-clt.zsh
./scripts/check-first-batch-clt.zsh --large
./scripts/check-shortcuts-clt.zsh
./scripts/build-clt.zsh
```

CLT 检查与 `FirstBatchRegressionTests` 共用相同行为断言。增加 `--shortcuts` 可以在同一编译结果中执行已有 862 项快捷键回归。`--large` 增加单层 4096² / 8192² 实际像素编辑、撤销及 PNG 导出。可选 `--psd <自行生成的样例.psd> <输出目录>` 写出整图、逐层和文字缓存对照，不读取其他文件。

24 种混合模式检查的是本机渲染、保存重开及枚举保留，不能作为与 Photoshop 公式逐一对照的证明。真实输入法、多层大型项目、长时间交互、压感设备和完整 Xcode 测试需分别记录；构建成功不替代这些验证。

安装时使用常规构建得到的 `Compositor.app`。保留当前工作，正常保存并退出后再打开新版本，无需安装 Xcode。

后续 CLI / MCP 约束见 [编辑命令契约](edit-command-contract.md)。
