# Windows 编辑器工具补全 / Complete editing tools

版本：0.3.0-alpha.1。Windows 与 macOS 同仓库、分别安装、分别存储设置与恢复副本。本批只修改 Windows 实现和 Windows 文档；项目继续保存为 macOS 已定义的 v11 字段。

## 使用范围

| 类别 | 可用能力 | 操作语义 |
|---|---|---|
| 文件 | 新建、宽高互换、PNG/JPEG 导入、PSD 导入、打开/保存/另存、PNG/PSD 导出、恢复副本 | 覆盖保留原包备份；未知字段和原资源保留 |
| 选择 | 矩形/椭圆选框、套索、魔棒；替换/加/减/交；全选/反选/取消/扩/缩/羽化 | 文档坐标覆盖蒙版；选区可撤销，不写项目或触发文件未保存标记 |
| 绘画 | 画笔、橡皮擦、硬度/间距/压感、前后景色互换、双轴/径向对称 | 每次完整笔画一次提交；选区限制同一填充/绘画路径；径向 2–16 份 |
| 修整 | 污点修复、Alt 取样仿制、模糊/涂抹/推移 | 从邻近纹理或指定来源取样；是有界 CPU 算法 |
| 填充 | 线性/径向渐变、反向/透明、油漆桶、前景色填充/清除 | 临时桶区域与当前选区相交，不改当前选区；可取样活动层/合成图 |
| 文字 | 中文输入、换行、字体/字号、RGB、左右/中对齐、字距/行距、文本框、选中文字颜色/字体 | UTF-16 范围；保存文字参数与像素；应用前可预览，取消不提交 |
| 形状 | 矩形、椭圆、直线；圆角、线宽、颜色；重开后编辑 | 保存现有参数化 shape 和 PNG；像素编辑会明确栅格化 |
| 变换 | 多层移动/整体缩放/旋转/翻转、位置/尺寸、画布手柄、组传导、独立蒙版变换 | 旋转外接框作为对齐范围；位置为文档坐标；解除链接的蒙版随图层变换保持原文档位置，画布尺寸操作则调整所有蒙版坐标；蒙版解链后可编辑其位置/尺寸/旋转 |
| 图层 | Ctrl/Shift 多选、关键图层、6 对齐/4 分布、编组/解组、组树复制、删除、合并/拼合、栅格化 | 选择/画布/关键对象参照；不足 3 个目标的分布无移动；合并要求连续同级目标 |
| 蒙版 | 创建/显露/隐藏/反转/启停/链接、选区转蒙版、应用蒙版、绘制蒙版、剪贴源 | 灰度 PNG；应用后删除蒙版与失效可编辑元数据 |
| 外观 | 24 种候选混合、12 类调整层、6 类图层效果 | 未完成 macOS 黄金图定标；不宣称逐像素一致 |
| 滤镜 | 21 项滤镜与预览/取消/应用，含马赛克、锐化、曲线、曝光、渐变映射 | 应用一个撤销步骤；预览不动文档；复杂背景/结构修复存在限制 |
| 导航 | 抓手/缩放工具、适合窗口/100%、网格、吸附、参考线 | 参考线按已有 guides 保存；网格/吸附为会话设置 |
| 剪贴板 | 图层复制、合并复制、剪切、原生图像粘贴 | 选区限制复制/清除；文字框继续使用原生文本剪贴板 |
| 防误操作 | 内容/位置/外观/透明度锁定、撤销/重做、异步提交修订号核对 | 锁仅本次打开有效，继承祖先组；后台操作失败不改文件/历史 |

左侧 17 个工具按惯常的单列工具栏排列。小窗口可以滚动工具栏；顶部只显示活动工具参数，文件/选择/图像/图层/滤镜入口同时放在原生菜单中。右侧属性里的对齐、选区和参考线分区可折叠。

## 快捷键

- V 移动、M 选框、L 套索、W 魔棒、C 裁剪、B 画笔、E 橡皮擦、J 修复、S 仿制、R 涂抹、G 渐变、K 油漆桶、U 形状、T 文字、I 取色、H 抓手、Z 缩放。
- X 交换前后景、D 恢复黑白；Alt 单击仿制工具设置来源；Alt 取背景色或缩小；Shift 调整大小保留比例。
- Ctrl+A 全选、Ctrl+D 取消选区、Ctrl+Shift+I 反选；Ctrl+C/Ctrl+Shift+C 复制/合并复制、Ctrl+X 剪切、Ctrl+V 粘贴。
- Ctrl+G 编组、Ctrl+Shift+G 解组；Delete 清除当前选区，或删除所选图层。
- Escape 取消笔画、裁剪或预览；Enter 应用裁剪。中文输入组合过程中不截获快捷键。
- Ctrl+Z/Ctrl+Shift+Z 撤销/重做；Ctrl+S/Ctrl+Shift+S 保存/另存；Ctrl+0/Ctrl+1 适合窗口/100%。

## 数据与实现约束

共享编辑函数以局部文档副本构造完整候选，许可判定检查所有目标与祖先组，验证后才发布。图层变换、栅格操作、锁定、菜单与工具入口共用这条路径。填充与油漆桶共用覆盖蒙版，算法不会偷偷替换当前选区。

落在图层外、透明度为零等没有改变像素的笔画保留文字/形状元数据和已保存状态。内容锁阻止向锁定组插入图层；位置锁同时限制编组、解组、排序和所属组调整。IPC 传递普通参数与二进制数组，不把界面响应式对象传入编辑后端。

耗时栅格操作在 Node 工作线程执行，最长 30 秒，超时终止并保留原状态。滤镜预览在独立浏览器工作线程执行；取消会销毁线程。提交绑定具体文档 ID 和修订号，旧结果不能落入新文档。

文字/形状使用当前 macOS 参数模型与像素后备，不新增任意矢量路径或插件格式。文字编辑依赖 Windows 本机字体；缺失字体的既有像素保持不变，重新应用时会按后备字体重排。文字转曲/任意钢笔路径不在两个编辑器当前共享模型内。

锁定不写入 manifest。未来跨平台持久化锁需要两端共同约定；目前不能把一次会话锁伪装成永久保护。非默认不透明度或带蒙版的组拒绝直接解组，以免丢失外观。非正常混合或跨边界剪贴关系的局部合并拒绝；完整拼合可以烘焙当前合成结果。

选区与新栅格操作限 1600 万像素；其余读取、渲染、历史预算继承安装说明。读取到不支持的可见属性时明确回退并禁止视觉编辑，仍可无损保存副本。

## 验收与实际边界

本机不运行测试、构建或应用。执行验收交给 Windows GitHub Actions：类型检查、纯算法、事务与格式保持、异步持有者、独立 PSD 读取、真实打包 EXE 的工具操作、保存重开、中文文字与形状、两种窗口尺寸、包内容/隐私/许可证检查。精确通过数量与运行链接在发行说明记录，失败时修复后重跑完整候选。

这是覆盖日常编辑工作流的 Windows 实现，仍为预发布。真实 Win10/Win11 显卡、触控笔、中文输入法、高 DPI、多屏和用户项目实机验收、macOS 黄金图、Photoshop/Photopea 人工打开尚未完成。云端软件 GPU 或程序化中文输入不等于这些项目已通过。
