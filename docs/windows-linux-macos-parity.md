## 共同验证约束

- 合成样本覆盖原始资源字节保持、像素编辑后资源替换、保存重开、恢复与撤销。
- 新格式记录严格验证，未知或损坏数据明确拒绝，不通过提高版本上限或删除记录来伪装兼容。
- Windows 与 Linux 的实际安装包各自运行测试；真实输入法、压感设备、硬件 GPU 和高 DPI 另列验收。
- 更新仓库时保留 macOS 文件和发布，Windows/Linux 各用独立产物与发行渠道。

## 本地增量验证（2026-10-27）

195 项单元测试、TypeScript 检查和源码隐私扫描通过。Linux 实际包验证多格式导出/印刷预览、v17 原图、填充/路径/矢量蒙版；完整 GUI 回归及两端 CI 正在继续。Linux 基础分支的包审查失败仍在调查，不作为通过记录。当前仓库分支属于开发中的移植，尚未完成全部功能，也未更新发行包。

## 可编辑滤镜增量

已加入 v14/v15 步骤资源及严格验证、源图与缓存分离、损坏步骤拒绝加载、复制/栅格化/像素编辑的资源归属规则。200 项单元测试通过；七种液化工具与 macOS C 位移/冻结场误差小于 0.00001，合成不透明样本像素误差不超过 1。Linux 实际包的滤镜栈/液化保存重开、25 种滤镜预览应用、GPU 丢失保护及结构化图层四组增量回归通过。先前完整 GUI 为 57 通过、1 失败，失败项“内容识别填充”已定位为选区字节复制错误并通过整组复查；完整最新构建仍待两端 CI，不能据此将全部功能标为完成。

## 字体与打包增量

文字使用本机字体；fontkit 与全部传递依赖锁定，打包保留 MIT 声明、Brotli 解码器的 Google 原始版权头及 Apache-2.0 全文，项目和安装包均不嵌入系统字体。Linux 原生库审查失败已在本机复现为 npm 同时安装 glibc/musl 可选依赖；构建明确排除当前 glibc 包不使用的 musl 库，保持包审查规则严格。Linux 实际包的 146 个文本资源隐私扫描无匹配，依赖/许可证审查通过到安装包数量检查；三格式审查及完整两端 CI 待后续结果。

## 操作入口增量

命令查找支持 Ctrl+Shift+P、中英文交叉搜索、快捷键与不可用命令提示；历史面板在保留的预算范围内跳转，旧调用和处理中调用明确拒绝，新的编辑截断重做分支。重复滤镜保留上次成功应用的完整设置（含 LUT），取消草稿不会替换它，重复时使用当前图层与选区。Linux 实际包验证了这三者的联动及源包不变。三种 Linux 格式的结构检查也已通过：AppImage、Deb、tar.gz 中应用字节、原生库、许可证与沙箱启动器一致；该结构检查使用的是前一增量候选包，不代表本轮全部源码的完整 GUI 验收。

## 导航与颜色增量

导航面板可点击/拖动定位和键盘平移，标尺按当前分辨率显示像素/英寸/厘米并可拖出可撤销参考线；视图和色板不会改变项目保存状态。RGB/HSV、二维饱和度/亮度、前后景和自定义色板与网格参数只写本机独立设置文件，字段白名单、尺寸上限、原子写入和路径链接检查均已验证。Linux 实际包验证重启恢复；另复查了命令查找、历史、原生文字撤销、选区蒙版与结构化图层五组。Windows 上两处保存断言尚未通过，已改为等待磁盘事务与恢复清理完成（30 秒上限、界面错误立即失败），待新 CI 明确结果，不将其记为已修复。

## 多项目与保护增量（2026-10-28）

标签页在本次运行中保留各自的历史、未保存状态、锁定、选区和视口；同路径重复打开切回原标签，同文档 ID 的其他副本明确拒绝，防止恢复记录相互覆盖。最多 8 个项目并共享 512 MiB 资源/历史预算，另存为不能覆盖其他标签打开的位置。逐标签取消关闭保留项目；退出取消也保留其他项目恢复记录。最近列表默认只在内存中保留，勾选后才以原子写入和 0600 权限保存最多 20 项；清空仅删除记录。外部更改提醒可以忽略当前版本，后续改动会再次提醒；覆盖保存仍执行原有磁盘指纹检查。灰度与未锁定副本在新标签打开，不改动原项目。

212 项单元、类型检查、源码隐私扫描及 Linux 实际包的标签/重启/外部变化、导航、本机文字历史 4 项增量全部通过。此前导航阶段 Linux 完整 GUI 62/62 通过；当前工作区版本完整回归正在运行。Windows 导航提交 `fa23ea0` 云端检查 59 项通过、3 项 Linux 专属跳过，安装包检查通过（运行 40543482411）。同期 Linux 云端的图层选择时序失败已让处理中按钮明确禁用，本机完整旧版 62 项通过，本次继续回归。仍未完成表中其他能力，也未发布新的安装包；macOS 文件和发布未修改。
