# 色彩范围入口与自动化审查

日期：2026-10-03。

## 问题与处理范围

曾出现自动化停留在“选择”菜单、菜单元素失效及无法返回画布截图的情况。本次在旧安装版本中重新打开“选择 → 色彩范围”，操作成功，面板截图正常，未稳定复现原始错误。因此不能把接口的旧元素错误认定为应用死锁，也不能宣称已经修复自动化工具内部的窗口缓存或截图实现。

应用侧为选框、套索和智能选择工具增加“色彩范围…”直接按钮，使用既有 `beginColorRange()` 和 `canSelectColorRange`。入口不经过菜单跟踪，不增加另一套选区算法或编辑许可。菜单入口仍保留。

直接按钮、菜单命令、取样模式、容差字段和确认/取消按钮具有稳定的无障碍标识。标识用于重新定位控件；它不能让已经失效的原生元素引用重新有效。

## 操作方法

导入图像后，按 M、L 或 W，点击工具栏“色彩范围…”。打开面板后按当前窗口重新获取控件，再修改参数。面板有“取消”和“好”按钮，取消后返回画布。

自动化遇到失效元素时，应重新读取当前界面。菜单跟踪期间不能把菜单快照当作画布快照；可使用菜单提供的 Cancel 无障碍动作结束跟踪，再重新获取画布。不要对旧索引反复点击，也不要因接口错误直接强制退出应用。
