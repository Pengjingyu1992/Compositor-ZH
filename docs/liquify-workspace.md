# macOS 液化工作区

液化专项已交付手动液化完善，版本 1.4.5（40.15）。海报与照片编辑第二批 T06–T13 另见 [该批说明](macos-poster-batch.md)。

## 使用

「涂抹 → 基础液化」在主画布直接推动像素；「滤镜 → 高级液化…」打开完整工作区，默认快捷键为 ⇧⌘X，可在快捷键设置中修改。基础液化工具栏同时提供高级液化入口。高级工作区需要选中一个可见、允许编辑内容的图层。

高级入口沿用基础液化笔刷的大小、硬度及强度；应用成功后将这些设置带回基础工具，取消则保留进入前的设置。普通画笔和仿制图章的独立笔刷设置不受影响。基础笔刷使用文档像素，高级笔刷使用图层原始像素；缩放图层时自动换算大小，不等比缩放时以面积对应的等效圆换算。

- 向前推动、旋转（可反向）、收缩、膨胀、局部重建、冻结及解冻。
- 笔刷大小、硬度、力度、速率和数位笔压力；旋转/收缩/膨胀/重建按经过时间累计，单次间隔最多计 100 ms，避免长时间停顿后突然跳变。
- 固定边缘、冻结覆盖、网格、其他图层的位置参照、原图对比、缩放/平移。
- 默认按住空格拖动平移；滚动平移，Command 滚动缩放；触控板捏合缩放。
- 与基础工具共用笔刷按键：`[` / `]` 调大小，`Shift-[` / `Shift-]` 按 25% 调硬度，`1–9` 设 10–90% 强度、`0` 设 100%，快速输入两位数设置精确百分比。支持中文方括号与自定义按键，打开工作区即有效；参数控件获得焦点后仍有效，文本输入保留原行为。
- 右键拖动调整笔刷大小，Shift 右键拖动调整硬度。笔触及应用进行中不改变笔刷参数；撤销/重做使用现有自定义按键并仅作用于高级液化内部历史，应用/取消也沿用统一按键设置。
- 冻结只保护后续笔触，不撤销此前变形。局部重建减弱已有位移；「恢复全部变形」恢复原图位移，「全部解冻」清除冻结。两种整体操作均可在工作区撤销。
- 窗口上方按钮逐笔撤销/重做。笔触历史限制为 100 步 / 64 MiB，超限移除旧步骤并显示提示。
- 默认生成副本并隐藏原图层，作为一次主历史操作；也可应用到当前像素图层。文字和形状强制生成像素副本，保留原始可编辑图层。
- 取消和无实际像素变化的应用不会改变文件。应用后可以从主编辑器一次撤销，恢复原图及其可见性。

工作区按图层原始像素方向编辑；文档中的旋转、翻转、缩放及蒙版保持原值，当前选区按文档坐标转换后限制结果。其他图层仅作为位置参照，半透明显示，不是完整效果/调整层合成预览。选区外像素不改动；透明度锁保持原 alpha。

## 安全与资源

编辑绑定文档 UUID、修订与编辑实例。工作区打开期间阻止其他文档编辑与标签切换，退出会取消工作区；提交时再次检查身份、目标和锁定。取消或文档变化后返回的旧结果不能应用。

所有笔触修改同一份逆向位移场，预览和最终结果均从进入时的原图取样；不会把上一帧的重采样结果当作下一笔原图。双线性取样作用于预乘 RGBA，边界使用原图边缘值，避免透明黑边。

长边最多约 1,536 个网格间隔，小图使用逐像素位移网格，大图使用平滑插值的稀疏网格。大图的极细小变形和冻结边界受网格间隔限制。最大笔刷 3,000 原图像素。

Metal 用于 16 MP 以内的取样，位移更新共用 CPU 模型；设备/分配/命令失败回退到 CPU。更大图层使用 CPU 分行渲染。预算估算分别包含原图、规范化像素、输出/读回、可选 GPU 副本、选区、位移及历史余量；上限为 1.5 GiB 和物理内存四分之一中较小值，超限在分配前拒绝。

工作区内逐笔撤销与主历史独立。应用 8K 结果后，主历史仍受现有 256 MiB 默认预算限制，可能无法保留该次撤销；主编辑器会明确提示。默认副本保留原图，但不替代保存备份。

本批没有新增 `.comp` 字段，应用结果保存为普通像素。人脸识别、重新打开位移参数、智能滤镜和 PSD 可编辑液化留待后续。

## 验收

```sh
./scripts/check-liquify-clt.zsh
./scripts/check-liquify-clt.zsh --shortcuts --large
./scripts/check-localization.zsh
./scripts/build-clt.zsh
```

`--shortcuts` 同时执行第一批和快捷键回归；`--large` 实际运行 4K/8K 连续 60 次位移更新、全尺寸渲染及逐笔撤销/重做。`--output <目录>` 生成一份不含私人照片的测试项目用于界面验收。

需要分别记录：工具行为、冻结/解冻、选区、预乘 alpha、CPU/Metal 像素误差、历史分支、取消与旧回调、超预算拒绝、性能及界面操作。真实数位笔压力和长时间多层项目不能用合成测试代替。
