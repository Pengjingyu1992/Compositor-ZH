# macOS 第三、第四批：现状核对与修订计划

更新：2026-10-09。基线：macOS 1.4.8（40.19），仓库 `013400a`；项目读取 `.comp` v1–13，新保存写 v13。

本计划最初按上述基线对照源码和菜单整理。用户随后选择仅实施 4A 与 4C，40.20 的具体范围见 [可编辑滤镜与液化说明](macos-editable-filters.md)；4B 与 4D 后延。历史验收不作为新能力的实测结果。

## 二、第三批：完成归档，按证据修复

T14–T15 首次交付于 40.18，40.19 已包含。操作见 [路径批次说明](macos-paths-batch.md)，互通边界见 [PSD 导出说明](psd-export.md)。

保留以下已知边界，避免将范围限制误记为 Bug 或再次承诺已完成：

- 沿路径文字是一条路径上的单行横排，文字保存路径副本；编辑原路径不会自动更新文字。弧形弯曲也不覆盖全部 Photoshop 文字变形预设。
- 文字转轮廓后可编辑锚点，不能再编辑文字内容；无可用轮廓的字形会拒绝转换。
- PSD 的竖排、沿路径、弯曲、非等比缩放文字及多色轮廓保留像素；普通横排文字仍依赖接收端字体和排版。
- PSD 的图案填充、非整画布对齐渐变保留像素。可编辑调整当前限反相、色阶、曲线、曝光；其他调整、图案叠加、斜面等要求合成导出。
- PSD 导入时同时存在像素/矢量蒙版会明确合成像素蒙版；形状/填充占用 PSD 矢量槽时，额外蒙版作为像素蒙版输出。

**后续只将支持范围内的可复现错误列为修复任务。** 原生模型保存丢失、取消/撤销错误、锁定旁路、已支持 PSD 记录写错或转换提示不准确，均可进入修复；本次没有据此宣布新的已确认缺陷。

动态路径链接、多行沿路径文字、更多文字变形、更多 PSD 调整/填充映射分别作为扩展候选，保留需求但不与已交付基础重复计数。原生编辑能力、PSD 结构可编辑性及外部重新渲染外观分别验收。

## 三、第四批：仅补真实缺口

### 4A · T16 逐图层滤镜栈（先做共同基础）

**交付：**保留源内容，给同一图层添加多个滤镜；可修改参数、排序、启停、删除，保存重开后重新计算。

- 复用现有 `PixelFilter`、调整参数和预览面板；保留已有调整图层的用途，不迁移或重复实现它们。
- 共同模型明确源内容引用、节点 ID/类型/版本、完整参数、随机种子、启停、混合与蒙版，以及坐标和执行顺序。模糊扩边、图层/滤镜蒙版与样式的先后关系须固定。
- 首个支持集合建议为高斯模糊、动感模糊、添加杂色、彩色半调和 LUT；这定义的是滤镜栈覆盖范围，不是新增五套滤镜算法。每种节点保存完整参数和所需资源，不能只保存通用 `amount`。
- 原图、可编辑内容与派生缓存分开；缓存不是唯一内容。已有像素层不能自动恢复应用滤镜前的原图；应保留当前外观作为转换起点。
- 首版明确支持的图层类型；对文字、形状、填充、组和蒙版的未支持组合明确拒绝，或通过有说明的对象转换保留源内容。

**完成条件：**重排产生符合约定的结果；全部停用还原源内容；保存重开可继续修改；预览、导出、恢复副本一致；损坏/未知节点明确处理，不静默丢弃；4K/8K 的缓存、读回与历史共同受内存预算限制。

### 4B · T17 嵌入式智能对象

**交付：**有独立内容容器的对象、替换源、内容编辑入口及实例更新；保留对象外部变换、蒙版和滤镜栈。

- 普通像素层已将图片嵌入 `.comp`，常规缩放/旋转/翻转只改 `transform`，不反复改写源像素。单纯嵌入图片或加一个“智能”名称不算本项完成；选区变形、透视和图像重采样另有像素处理语义。
- 使用 4A 的内容引用和渲染缓存，避免另建一条滤镜处理链。源内容可先限定为图像，但必须可在独立编辑上下文打开、修改并提交到对象实例；对象支持范围在界面说明。
- 固定重复缩放、裁剪、替换不同尺寸源、对象蒙版与滤镜坐标的规则；共享实例或独立副本要有明确操作语义。
- 嵌套对象、链接文件更新/丢失和 PSD 可编辑智能对象分开扩展。当前 PSD 的栅格导入不计为已具备智能对象。

**完成条件：**修改源内容可更新约定的实例；替换源保留约定的外部变换/蒙版/滤镜；重新计算仍从对象源内容取样；取消和失败保留旧源；嵌入资源完整保存、移动、恢复和重开。普通图层原有缩放保真只做兼容回归，不计为新增交付。

### 4C · T19C 持久可重编辑液化

**交付：**应用并保存项目后，可重新打开该次液化，继续修改已有变形。

- 保存原始内容、位移数据、保护蒙版、选区作用范围与坐标语义；接入 4A 的节点/资源体系，复用现有液化核心和工作区。
- 沿用现有七种手动工具、基础/高级液化入口及画笔快捷键；按用户决定，平滑、左推不恢复。
- 明确多次液化、源内容替换、尺寸变化与笔触重建的规则。既有普通像素液化结果无法自动还原旧位移。
- 原生 `.comp` 重新编辑与 PSD 智能液化互通分开承诺，不能用栅格缓存冒充外部可编辑滤镜。

**完成条件：**应用、关闭、重开后继续编辑；停用恢复源外观；冻结/选区约束保持；一次应用可撤销；CPU/GPU 输出和大图内存独立验收。

人脸识别、五官控制仍保留为独立后续项；识别质量与人工效果另验收，不作为手动液化持久化的前置条件。

### 4D · T18 动作录制与多文件处理

**交付：**录制已支持操作，编辑步骤/参数，选择多个输入文件执行并另存，展示进度、取消及逐文件结果。

- 在现有编辑命令/事务上增加语义录制，记录成功提交的操作；不记录界面点击、鼠标轨迹或预览滑块的每次变化。
- 明确可录制命令清单；现有 21 类命令不代表全部 GUI 功能已覆盖。Camera Raw 目前未开放，部分滤镜仅有简化参数，需按实际录制范围补齐，不能默认所有操作可录制。
- 动作目标用“当前图层”、明确名称匹配或“本动作创建的图层”等可解析引用；名称重复/目标缺失有处理策略。不能把某份文档的 UUID、历史修订或 `EditOwner` 原样复用到另一文件。
- 每个文件重新解析目标、取得当前身份/修订/许可，在候选文档上执行，成功后一次提交；复用 `BatchImageExporter` 的尺寸、命名和编码能力。
- 默认创建新输出、不覆盖输入；每个文件提交独立。取消或后续文件失败不能声称已经输出的其他文件整体回滚。失败清单可重试，重试重新检查输入与目标。

**完成条件：**同一动作在两份不同文档中正确解析目标；可中断、重试和定位失败步骤；失败文件不残留半完成项目；已完成输出可识别；源文件保持完整；中文/英文的步骤与错误可读。

基础动作界面可在现有命令上独立推进；只在录制新滤镜栈、对象或液化步骤时依赖对应模块，不必等待全部 4B/4C 完成。

## 四、实施顺序与共同约束

当前决定：**第三批归档；本次只做 4A 与 4C。** 以下保留的 4B/4D 技术说明属于后续候选，不作为本次验收范围。

1. **项目格式：**40.20 增加 v14 的源资源、滤镜节点和持久液化记录；普通应用保存仍为 v13，含这些步骤的项目写 v14。资源和拒绝规则见项目格式文档。对象不在本次格式内。
2. **跨端边界：**Windows 桥接目前明确只接受 v1–13。未知字段透传不能绕过版本拒绝。未来需单独安排最小读取/透传适配，或明确拒绝新版本，不能静默丢内容。本次不修改 Windows 实现或已安装应用。
3. **许可与事务：**沿用 `EditOwner`、锁定及候选文档提交；切换文档、修订变化、取消和旧异步回调不能串写。全图缓存失效不能误清未保存状态。
4. **一致性：**保存、恢复、预览、导出和 PSD 转换共用明确的源/派生关系。PSD 可编辑映射、自回读、独立读取器、真实外部编辑器分别记录结果。
5. **资源：**原图、位移、保护蒙版、滤镜缓存、GPU 中间目标、读回副本和历史一起预算；不以单张输出图大小代替峰值内存。取消任务应释放自己的暂存资源。
6. **本地化与验收：**固定撤销名和动态模板入词条；支持行为做定向回归，中文输入、数位笔、跨软件与持续性能的实际检查注明设备和未执行项。构建成功不替代功能或性能验收。

## 五、从旧缺口清单移出与保留的独立项

- **已具备，勿重复排期：**可编辑填充/样式、手动修边、彩色半调、中文竖排/两端对齐、CLI/MCP、多尺寸导出、调色扩展；以及对齐/分布、油漆桶、马赛克、恢复副本、历史和锁定。详见 [海报批次](macos-poster-batch.md)、[液化说明](liquify-workspace.md) 和 [首批说明](macos-first-batch.md)。
- **已有部分基础：**RAW 导入/开发与 Camera Raw，CMYK ICC 软打样及 CMYK TIFF 已实现。RAW 导入的高精度计算和最终量化不等于完整 16/32 位项目编辑；彩色半调的 CMYK 网角也不等于 CMYK 文档。
- **继续独立规划：**完整 16/32 位编辑、持久 RAW 开发参数/源文件工作流、CMYK 文档/通道/分色/叠印/PDF/X、多画板、复杂 AI 处理、笔刷资源兼容、人脸液化及扩展路径排版。不要用这些大项反复扩大 T14–T18 的基础交付定义。
