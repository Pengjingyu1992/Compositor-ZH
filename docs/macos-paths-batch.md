# macOS 路径与可编辑 PSD / Paths and editable PSD

第三批 T14–T15 在原生 macOS 编辑器内实现，不依赖云服务或 API Key。

## 钢笔与路径

- 按 **P** 选择钢笔。点击添加锚点，拖动生成对称控制柄；点击起点闭合，双击结束开放路径。
- 选择已有路径后点击“编辑路径”。拖动锚点或控制柄；按 Option 拖动控制柄解除对称，Option 点击锚点移除控制柄；Delete 删除选中锚点。
- “新建子路径”可添加孔洞或多个轮廓。“奇偶填充”控制相交区域与孔洞；可分别启用填充、描边并调整宽度，使用前景色按钮更新颜色。
- Return/“应用”一次提交，Esc/“取消”放弃草稿。草稿不改动项目；切换工具或退出时取消，文档变化后旧草稿不能提交。
- 图层菜单 → 路径与文字 → “文字转轮廓”：使用系统实际字体（含中文字体回退）生成可编辑锚点，保留字体/颜色区间。转换后无法修改文字内容，撤销可恢复文字层。无轮廓的彩色/位图字形明确拒绝转换。
- 先多选文字层与路径层，使路径成为活动图层，选择“沿路径文字”。在文字工具中调整偏移或反向；路径太短时明确拒绝。路径是文字内保存的副本，不与原路径建立动态链接。仅支持一条路径、一行横排文字。
- 普通文字的“弧形弯曲”保存为可再次调整的文字参数。弯曲按文字框计算，框外内容会被裁切；它不是 Photoshop 的全部文字变形预设。
- 活动路径 → “在下方图层创建矢量蒙版”：在紧邻的下方像素层上建立蒙版，隐藏源路径；目标已有蒙版时拒绝。选择目标 → “编辑矢量蒙版”可修改其节点。像素绘制或重采样蒙版后转为普通像素蒙版。

路径采用图层局部归一化坐标；锚点及两控制柄、开闭状态、填充规则、颜色与描边均保存。图层变换、复制、画布裁剪、撤销及重开保留模型；破坏性像素编辑或图像重采样会栅格化。PNG 是显示后备，不是路径的唯一数据。

## PSD 编辑结构

文件 → 导出 PSD，选择分层导出。支持范围与限制见 [PSD 导出说明](psd-export.md)。导出保持源项目与未保存状态，不把 PSD 导出当作项目保存。

- 普通横排文字保留文字、字体、字号、段落框、对齐、字距、行距与 UTF-16 字体/颜色区间。
- 导出记录系统实际使用的中文回退字体。接收电脑仍需安装对应字体；Photoshop 首次打开可能提示更新文字图层，更新会使用其自身排版。已在 Photoshop 2026 检查中文、混色文字与可编辑图层。
- 单色路径与基本形状输出矢量蒙版、填充及描边。彩色轮廓以像素保留；竖排、沿路径、弯曲或非等比缩放文字以像素保留。
- 单色填充及整画布对齐的线性/径向渐变输出可编辑填充。图案、非整画布渐变保留像素。
- 反相、色阶、曲线、曝光可保留调整参数；其他调整要求合成导出。
- 颜色叠加、投影、内阴影、内/外发光、描边与线性/径向渐变叠加保留参数。斜面及图案叠加要求合成导出。跨编辑器的光照、插值、字体布局可能不同。
- 普通像素层的矢量蒙版可导出为矢量蒙版；路径/填充层同时有蒙版时，额外蒙版保留为像素蒙版。导入同时存在像素与矢量蒙版的 PSD 时，将两者合成为像素蒙版并提示。

不是 Photoshop 全格式或全效果兼容实现；外部程序重新生成的文字/效果可能与缓存预览不同。导出提示会说明转换，不静默假装所有内容可编辑。

## 项目兼容与命令接口

保存使用 `.comp` v13，继续读取 v1–12；旧版应用会拒绝 v13，请先复制项目再交换。Windows 桥接识别并保留 v13 记录；可见路径、新文字布局或矢量蒙版采用项目预览并限制视觉编辑，缺少预览时明确拒绝。Windows 新建项目仍为 v11。

CLI/MCP 与“编辑命令”面板共用事务入口。新增 `addPath`、`editPath`、`textOutlines`、`vectorMask`；`addText`/`editText` 接受保存于文字样式的 `pathLayout` 和 `warp`。批量命令成功后一次提交/撤销，失败不留下半完成文档。路径字段见 [项目格式](project-format.md)。

## 开发验收

`./scripts/check-poster-clt.zsh --output <temporary-output-directory>` 同时检查路径/PSD 与第二批、液化、第一批和快捷键回归。Xcode 测试 target 自动同步新测试文件；本机 CLT 检查与完整 Xcode 测试不等价。

独立 PSD 读取：在临时目录安装 `ag-psd@31.0.2`、`pngjs@7.0.0`，然后运行 `node scripts/check-editable-psd.cjs <output-directory> <dependency-directory>`。合成预览逐像素比对，结构检查文字区间、路径、渐变、调整、效果与蒙版；真实外部编辑器打开仍需单独记录。

本批验证结果记录于交付报告，不把尚未运行的检查写为通过。
