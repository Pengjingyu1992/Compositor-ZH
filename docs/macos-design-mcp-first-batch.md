# macOS 界面与 MCP · 第一批基础改造

日期：2026-10-18。范围：B0 语义样式基础、P0 协议/工具目录/路由分离、沙箱传输原型及性能基线。界面与 MCP 的完整设计稿在本机设计目录维护，本文件记录已落地代码和验收边界。

## 本批实现

- `EditorTheme` 收拢工作区/导航器/导出及液化预览底色、工具选中态、工具栏/工具轨尺寸和字体。当前值与原实现相同，系统外观和新布局属于下一批可见界面交付。
- `MCPProtocol` 集中旧版初始化与工具结果/错误编码，保留原版本协商和响应结构。
- `MCPToolCatalog` 共享原有 11 工具的顺序、说明、输入 schema 和 21 命令枚举。
- `MCPDocumentHost` / `MCPToolRouter` 提供文档业务执行边界和共同入口参数校验；现有 CLI 作为 standalone Host 接入，候选文档原子事务不变。
- 原 `compositor-cli mcp` 继续独立内存文档模式；支持显式 `--standalone`。`--live` 当前明确返回不可用，未知选项拒绝，避免旧入口忽略参数后误开独立文档。
- `check-mcp-socket.py` 使用独立、临时、签名的 App Sandbox 原型验证容器内 AF_UNIX、同用户校验、0700/0600 和退出清理；原型不打开编辑器文档、不申请网络监听。
- `record-design-baseline.py` 记录现有性能 runner 的散列、硬件、耗时、进程峰值 RSS、退出结果和测量边界；提供超时与 RSS 预算，仅终止自己启动的 runner。

## 兼容纪律

- 不把现有历史 revision 改成单调计数；live 所需独立变更令牌在后续 Host 实现中加入。
- 保留 standalone 的保存副本行为、handle、同名 undo/redo/locks 参数与错误结构。
- 本批不声明 2026 协议支持，当前工具目录及初始化协议仍与旧 helper 一致。
- 实际 live Host、客户端配对/授权、画布预览工具与活动 UI 尚未交付；原型验证只证明当前机器上的传输可行性。
- UI 设计原型的暂停开关和状态演示不代表当前安装的应用已经具备 MCP 连接管理。

## 验收方式

1. CLT 编译 app 与嵌入式 CLI，并验证完整签名。
2. 以已安装 helper 为基准，对比初始化、11 工具完整 schema、协议错误和工具参数错误；运行已有 CLI/MCP 真实进程回归。
3. 运行签名沙箱传输原型，检查权限、UID、往返和退出清理。
4. 用资源受限记录器采集性能 runner；区分 4096 方形场景与混合 4K/8K 场景。不得把含夹具总耗时写成帧时间或输入到光子延迟。
5. 检查本地化与差异空白；只审查本批路径，现有 Windows 本地删除状态不纳入本批修改。

## 性能测量边界

目标 4K 3840×2160、8K 7680×4320 的真实交互基线仍需独立采集。现有 runner 使用 4096×4096 / 8192×8192 方形图像，包含夹具、100 次稀疏历史编辑，以及 large 模式下的 4K/20 层与 8K/10 层 GPU 场景。large 过程中提前结束不能直接定位为 8K 场景失败。

RSS 不等同于 GPU 分配或完整物理 footprint；不得把二者混称为应用总内存。首次不带资源限制的 large 运行异常结束，保留为失败记录，不列为通过，也不据此声称 8K 帧率。后续大场景只使用带预算的记录方式。

## 当前验收结果

| 项目 | 结果 |
|---|---|
| CLT app + CLI 编译、完整签名 | 通过；基础改造已随 40.28 的 PSD 修复一同安装 |
| CLI/MCP 真实进程回归 | 110 项，0 失败 |
| 与安装版协议对照 | 13 个响应相同；11 个完整工具 schema、21 种命令和顺序保持；显式 standalone 一致 |
| 模式保护 | live 未就绪明确拒绝，未知选项拒绝，不误落到独立文档 |
| 签名沙箱原型 | AF_UNIX 往返、同用户、0700/0600、退出清理通过 |
| 本地化 | 1,469 候选；缺失/未译/未解析运行时表达式均为 0 |
| 4096 方形内存/渲染 runner | 156 项，0 失败；100 次稀疏编辑历史 5,308,416 bytes |
| 4096 runner 进程基线 | 总墙钟 0.415 s，峰值 RSS 316.1 MiB；含夹具及检查，不是帧时间 |
| 混合 large runner | 2.775 s 达 RSS 停止线；记录器主动终止（exit -15），峰值 RSS 4422.1 MiB；未完成，不列通过 |
| HTML 交互原型 | 深/浅稿重渲染；800×520 工具滚动/焦点、更多参数、检查器、暂停状态通过 |

基线采集于 Apple Silicon Mac，完整机器配置仅保留在本机记录中。使用原有 40.27 runner，散列与日志在本地 `build/design-mcp-first-batch/`（忽略构建目录）。运行期间没有并行的应用编译。

大场景的 4 GiB 是进程 RSS 的采样停止线，允许采样间隙产生超调，不是 GPU 或整个系统的硬内存上限。此结果暴露了混合大场景的资源风险，尚未建立其 GPU 稳态或真实交互 FPS；下一步需分离夹具/首帧/稳态并按阶段采样，不用总耗时推断性能。外部客户端 live 授权、2026 完整协议与新布局的原生交互验收留在对应实施批次。
